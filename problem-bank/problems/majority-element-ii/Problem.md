# Majority Element II

Given an integer array of size `n`, find all elements that appear more than `⌊n / 3⌋` times.

Return the result sorted in ascending order.

### Examples

**Example 1:**
```
Input: nums = [3, 2, 3]
Output: 3
Explanation: 3 appears 2 times, which is more than 3 / 3 = 1.
```

**Example 2:**
```
Input: nums = [1]
Output: 1
```

**Example 3:**
```
Input: nums = [1, 2]
Output: 1 2
```

### Constraints

- `1 <= nums.length <= 5 * 10^4`
- `-10^9 <= nums[i] <= 10^9`
