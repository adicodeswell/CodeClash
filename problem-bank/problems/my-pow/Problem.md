# Pow(x, n)

Implement `pow(x, n)`, which calculates `x` raised to the power `n` (`x^n`).

Return the result as a double.

### Examples

**Example 1:**
```
Input: x = 2.0, n = 10
Output: 1024.00000
```

**Example 2:**
```
Input: x = 2.1, n = 3
Output: 9.26100
```

**Example 3:**
```
Input: x = 2.0, n = -2
Output: 0.25000
Explanation: 2^(-2) = 1/(2^2) = 1/4 = 0.25
```

### Constraints

- `-100.0 < x < 100.0`
- `-1000 <= n <= 1000`
- Either `x` is not zero or `n > 0`
- `-10^4 <= x^n <= 10^4`
