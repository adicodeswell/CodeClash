# Reverse Linked List

Given the head of a singly linked list as an integer array `head`, reverse the list, and return the reversed list.

### Examples

**Example 1:**
```
Input: head = [1, 2, 3, 4, 5]
Output: 5 4 3 2 1
```

**Example 2:**
```
Input: head = [1, 2]
Output: 2 1
```

### Constraints

- `1 <= head.length <= 5000`
- `-5000 <= head[i] <= 5000`
