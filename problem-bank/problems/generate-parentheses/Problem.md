# Generate Parentheses

Given `n` pairs of parentheses, write a function to *generate all combinations of well-formed parentheses*.

The return list should be sorted in lexicographical order.

### Examples

**Example 1:**
```
Input: n = 3
Output: ((())) (()()) (())() ()(()) ()()()
```

**Example 2:**
```
Input: n = 1
Output: ()
```

### Constraints

- `1 <= n <= 8`
